# GS-AUTOMATE

## Cross-Suite Workflow Automation & Pipeline Studio

You are implementing the FINAL major suite of the existing GS Softwares PWA.

The PWA already contains approximately 99 tools across multiple specialized suites.

The purpose of this new suite is to allow users to combine those existing tools into reusable workflows.

The user should be able to:

```
SELECT TOOLS
↓
CONNECT THEM
↓
CONFIGURE EACH STEP
↓
FEED FILES / DATA INTO THE WORKFLOW
↓
EXECUTE THE PIPELINE
↓
INSPECT EACH STEP
↓
RECEIVE FINAL OUTPUTS
```

The suite must support:

1. 30+ professionally designed prebuilt workflows
2. A fully custom workflow builder
3. Editing prebuilt workflows
4. Using prebuilt workflows as templates
5. Saving custom workflows
6. Duplicating workflows
7. Import/export of workflows
8. File/data input routing
9. Multiple outputs
10. Conditional execution where technically appropriate
11. Step-level configuration
12. Execution progress
13. Step-level logs
14. Failure handling
15. Retry
16. Skip
17. Continue-from-failure
18. Workflow history
19. Local-first execution
20. Zero-upload architecture

============================================================


# 4. NODE TYPES

The workflow engine should support more than tool nodes.

At minimum:

### INPUT

Receives:

* File
* Multiple files
* Text
* Folder where browser capabilities permit
* URL only if the existing application explicitly supports local/network retrieval
* Previous workflow output

### TOOL

Executes one of the 99 existing tools.

### TRANSFORM

Changes data representation.

Examples:

```
PDF → Image
Image → PDF
CSV → JSON
JSON → CSV
Video → Frames
Audio → Text
Text → Markdown
```

### CONDITION

Branches execution.

Example:

```
IF file type == PDF
→ PDF pipeline

ELSE
→ Image pipeline
```

### FILTER

Selects files/items.

```
files where extension == .png
```

### LOOP / FOR EACH

Execute a node or subgraph for each input item.

### MERGE

Combine outputs.

### SPLIT

Create multiple branches.

### OUTPUT

Exports or exposes final results.

### WORKFLOW

A workflow may itself become a reusable subworkflow.
