# GS SOFTWARES — GS-SLIDES

# NON-AI PRESENTATION / DECK STUDIO

## Research → Capability Classification → Architecture → Responsive UI → Interaction Specification

You are a senior product architect, UX engineer, frontend systems architect, document-engineering architect, and presentation-software researcher.

Your task is to research, define, and architect the **GS-Slides / Deck Studio** inside the GS Softwares PWA.

This studio is intentionally:

* Non-AI
* Browser-first
* Client-side
* Offline-capable
* Zero-upload
* PWA-compatible
* Local-file compatible

The current canonical tools are:

1. Markdown Slide Presenter
2. Slide Deck → PDF

The objective of this phase is:

**Research → Capability Classification → Non-AI Tool Taxonomy → Presentation Architecture → Canvas Architecture → Responsive UI → Interaction Design → STOP**

Do NOT implement advanced algorithms or unrelated AI functionality during this phase.

# 1. PRODUCT OBJECTIVE

GS-Slides should function as a professional browser-based presentation studio.

The user should be able to:

* create a presentation
* open an existing presentation/project
* write slides using Markdown
* preview slides
* navigate between slides
* reorder slides
* duplicate slides
* delete slides
* edit slide content
* inspect slide structure
* present fullscreen
* control presentation navigation
* export the deck to PDF
* save the project locally
* reopen the project later
* work without uploading files to a server

The product should feel like a native member of:

# GS SOFTWARES

rather than a standalone presentation application.

# 2. NON-AI BOUNDARY

This is NOT an AI presentation generator.

Do NOT add:

* AI presentation generation
* AI slide generation
* AI writing assistant
* AI image generation
* AI design assistant
* AI layout generation
* prompt boxes
* "Generate with AI"
* AI slide rewriting
* AI summarization
* AI speaker generation
* AI presentation coach

unless such functionality is explicitly added to the canonical GS-Slides tool registry later.

The current studio is a deterministic/browser-native presentation environment.
